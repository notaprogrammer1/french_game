# Roadmap

## v0.3 — current

- Terminal-first game loop
- Learn mode that gives answers directly
- Cumulative levels
- Pattern cards and word cards
- More examples per pattern
- Accent-insensitive feedback
- Session score
- Saved progress in `~/.french_phonics_game/progress.json`
- Review mode for cards that need work
- Light weighting toward weak cards in mixed drill

## v0.4

- Add per-level mastery thresholds.
- Add a guided "learn → drill → review" flow.
- Add a way to reset progress from inside the app.
- Add more cards per level.
- Add a "type accents only" mini-drill.

## v0.5

- Add real audio files or text-to-speech hooks.
- Add IPA as an optional display.
- Add minimal-pair drills:
  - `u` vs `ou`
  - `é` vs `è`
  - `an` vs `on`
  - `ch` vs `j`

## Later

- Add optional GUI, probably with Textual, Tkinter, or a web frontend.
- Add spaced repetition scheduling.
- Add user-created word decks.
